Support

For problems with MekDaa setup, saving or recalling sessions, Open a GitHub Issue.

Public issue warning: GitHub Issues are public. Never include private conversation text, Google Drive folder links or IDs, passwords, tokens, or screenshots containing personal data.

What to include in a bug report

  • Whether the problem happens during setup, save, or recall.
  • The steps to reproduce it using example data, with private details removed.
  • The MekDaa package version and a redacted error message, if any.

Common checks

Confirm your Google Drive integration is connected and the selected folder is accessible. If MekDaa cannot find your workspace in a new chat, send the link to your existing workspace directly to ChatGPT—not in a GitHub Issue.

Support is provided through GitHub Issues only. There is no separate private support inbox.
