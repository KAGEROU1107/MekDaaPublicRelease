A Google Drive–based ChatGPT session helper

Save a session. Pick up where you left off.

MekDaa helps you save a detailed summary of the ChatGPT conversation currently available to the assistant in your own Google Drive folder. Later, recall that saved record to continue your work.

How it works

  1. Connect an available Google Drive integration to ChatGPT.
  2. Provide the Drive folder link you want MekDaa to use as its workspace.
  3. Ask “Save this ChatGPT session to MekDaa.”
  4. In a later chat, ask “Recall my last saved MekDaa session.” If needed, provide the existing workspace folder link again.

What to expect

MekDaa is free and saves sessions only when you request it. It cannot recover chats that were never saved, capture messages unavailable to the assistant, or run background recording. Saved summaries are not guaranteed to be complete transcripts. You manage files and permissions in your own Drive.
